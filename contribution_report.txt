# Project Contribution Report## Samsung Artifact DetectionThis document details the individual contributions and collaborative efforts of the team members in the project for detecting and classifying image artifacts and distortions using Deep Learning.## Working Approach and Collaborative DevelopmentThis project is structured as an end-to-end pipeline where each phase depends on the next, our primary approach was cross-functional, collaborative development. All team members **Boaz Attiya**, **Linoy Avraham**, and **Inon Reani** actively engaged in every stage of development, contributed to all parts of the codebase, and evaluated diverse methodologies to deeply understand the domain and select the optimal project outputs together:* **Preliminary Research:** Conducted literature reviews and gathered shared foundational knowledge on image distortions and artifacts.* **Data Augmentation:** Co-authored functions to generate synthetic distortions from clean (Normal) images to build a comprehensive dataset for training when needed.* **Data Processing & Cleaning:** Developed data preparation functions, including slicing high-resolution images into 50 by 50 pixel patches and automatically partitioning files into directories based on distortion types.* **Model Development & Evaluation:** Collaborated on building a binary detection model and a multi-class classification model, alongside visualizing results and generating confusion matrices to analyze individual model performance.* **Pipeline Integration & NMS Algorithm:** Worked together to integrate all system components, developed the Non-Maximum Suppression (NMS) layer to filter duplicate bounding boxes, and established a unified, end-to-end data pipeline.* **Presentations & Briefings:** Jointly wrote, designed, and delivered technical presentations and performance evaluations directly to the engineering and development teams at Samsung.---## Individual Focus Areas and Product Engineering LeadershipFollowing the integrated learning phase, each team member took ownership of specific engineering modules to elevate the project into a stable, production-ready system with optimized performance, then together everyone reviewed and enhanced code, performance and understanding.### Linoy Avraham#### Binary Detection Network Architecture & Performance Evaluation - Dataset Management, Cleaning, and Balancing* **Data Preparation Pipeline:** Developed the workflow for deploying and filtering system sub-directories. Conducted active cleaning of irrelevant distortion types.* **Sampling Strategy & Under-sampling:** Resolved extreme dataset imbalance issues by limiting the number of samples to 1,405 images per allowed distortion category, accurately balancing them against 7,025 clean (Normal) images to create a symmetric training baseline of 14,050 images using a fixed-seed split.* **ArtifactCNN Architecture Development:** Implemented a binary CNN architecture (a sequence of 3 Conv2d layers, ReLU activation, and MaxPool2d, paired with a 0.5 Dropout rate in the linear layer) tailored for 50 by 50 pixel inputs.* **Optimization and Training:** Managed the learning process utilizing Early Stopping with a patience of 5 epochs. Analyzed Loss and Accuracy curves to lock in the most accurate model weights from Epoch 19, achieving a 97% Accuracy rate on the test set.* **Advanced Analysis & Validation:** Embedded a comprehensive evaluation framework including Confusion Matrices generation, accuracy breakdown per specific distortion type, and Bootstrapping tests to validate the model.#### Sliding Window Algorithm and Spatial NMS Mechanism* **SlidingWindowDataset Development:** Developed a dedicated dataset class that scans mega-pixel images using a sliding window with a stride of 10 pixels, utilizing Mixed Precision training and optimizing data transfer efficiency to the GPU.* **Spatial NMS Component Development:** Designed and implemented a filtering algorithm based on Non-Maximum Suppression. To resolve duplicate detections around the same defect, a mechanism that inflates the original bounding boxes using a fixed 20-pixel margin prior to the Intersection over Union (IoU) check. This mechanism enabled clustering nearby patches, eliminating noise, and cleanly extracting the true local maxima to export them into the suspected patches interface file.#### Project Documentation & Technical Writing* Authored and structured the project's official README file, designing it as a professional overview and a clear technical introduction for the engineering teams at Samsung.---### Boaz Attiya#### Preliminary Research, Statistical Processing, and Data Pipeline* **Distortion Research & Image Quality Metrics:** Conducted an in-depth study on various types of visual defects and distortions, reviewing Image Quality Assessment (IQA) methodologies, including Full-Reference and No-Reference metrics. Additionally, researched Image Aesthetics Assessment (IAA) models to better understand the visual perception characteristics of end-users.* **Baseline to Optimization Pipeline:** Designed and developed a fast, lightweight initial baseline model for distortion classification that achieved approximately 80% accuracy, followed by a comprehensive hyperparameter tuning process to determine the optimal architecture.#### Network Architecture, Optimization, and Training Logic* **Advanced Architecture Upgrade & Optimization:** Maintained full partnership in building, optimizing, and analyzing a deeper, heavier model utilizing GELU activation and Squeeze-and-Excitation blocks (SEBlock). Adapted the model to fit available computational constraints, boosting network performance to 90% accuracy.* **Residual Blocks & Classifier Design:** Implemented a network architecture consisting of 4 core ResidualBlock layers, alongside a final Classifier component utilizing Flatten layers, linear layers, and high regularization (0.5 and 0.3 Dropout rates) to manage a network encompassing approximately 20.2 million trainable parameters.#### Leadership, Management, and Communication* **Product Management & Client Relations:** Managed continuous, professional, and direct communication with Samsung to gather requirements, present milestones, and deliver accessible model deployments.* **Technical Integration & Advisory:** Took charge of synthesizing the team's complex architecture, executing codebase optimizations, and explaining the structural mechanics of the model to external stakeholders.* **Code Configuration Management (Git/GitHub):** Managed and maintained the complete GitHub repository, handling version control, branch merging, and the technical integration of all team members' code.---### Inon Reani* **Core Focus:** Multi-Class Patch-Based Classification model development, pipeline architecture and orchestration, GPU resource management, and system automation (CLI).#### Defect Classification Model Development* **Multi-Class Patch Classification:** Independently researched and developed the second model in the pipeline. This model takes targeted image patches flagged as potential anomalies by the first-stage binary detector and performs precise classification and labeling of the specific defect type out of a predefined set of categories.#### Core Pipeline Architecture and Orchestration* **Three-Stage Pipeline Engineering :** Designed and implemented the central execution script that orchestrates and synchronizes the sliding-window binary detection phase, the spatial statistical filtering phase (NMS), and the targeted multi-class patch classification model developed for the second stage.* **Data Flow Management & Output Schema:** Managed data ingestion and synchronized dynamic information exchange between the first and second models via temporary JSON files. Structured the architecture of the final output report (incorporating a coordinate map, binary classification score, precise defect classification, and network confidence level).#### Automation and Command Line Interface (CLI) Development* **CLI Development via argparse:** Built a flexible command-line interface allowing end-users to control internal system parameters and adjust both models without modifying code (e.g., modifying confidence thresholds via `--threshold`, tuning duplicate suppression sensitivity via `--iou`, and defining custom output file designations).* **Batch Directory Processing Logic:** Authored the handling logic that automatically detects whether an input is a single image file or an entire input directory. For directories, the system executes a parallel processing loop, extracts timestamps, and streams data into the classification model in real time to generate individualized reports.#### Dockerization and Hardware Optimization (GPU)* **Container Infrastructure Engineering:** Authored the Dockerfile and configured the isolated project environment, enabling full reproducibility of the model code and system integration across any machine or operating system without local dependency conflicts.* **Edge Hardware Optimization (NVIDIA CUDA):** Configured runtime parameters and structural configurations allowing the Docker container to directly access host GPU resources (`--gpus all`), leveraging hardware acceleration to accelerate concurrent inference across both models while managing volume mappings (`-v`) to ensure persistent local output generation.
